# オブジェクト指向ラボ（仮称）

車載の題材で、オブジェクト指向の設計の違いを「変更のしやすさ」で体感する学習 Web アプリです。概念ごとに「概念を使わない設計」「適切な設計」「やりすぎた設計」のコードを切り替えて比べ、仕様変更が来たときの修正量の違いを差分で確かめられます。コードは Java・C++・VBA で表示できます。

現在は開発中です（公開準備中）。

## 文書

設計の文書は [`docs/`](docs/README.md) にあります。

## 開発

Node.js 24 以上が必要です。

| コマンド | 内容 |
| --- | --- |
| `npm ci` | 依存ライブラリを入れる |
| `npm run dev` | 開発用のサーバを起動する |
| `npm run build` | サイトを `dist/` に生成する |
| `npm run preview` | 生成したサイトを、配信時のヘッダ付きで手元から配信する（Wrangler） |
| `npm run check` | 型を検査する |
| `npm run lint` | 静的検査（ESLint） |
| `npm test` | 単体テスト・結合テスト（Vitest） |
| `npm run test:e2e` | E2E テスト（Playwright。先に `npm run build` が必要） |
