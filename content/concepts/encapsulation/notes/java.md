- `private`: クラスの外から読み書きできない（適切）
- `public`: どこからでも読み書きできる（未適用）
- 拒否は `boolean` の戻り値で返す

::: くわしく

- **アクセス修飾子**: 何も付けないと、同じパッケージ（関係するクラスをまとめる単位。この教材のコードはすべて1つのパッケージ）の中からだけ使えます。適切な設計の `shiftTo` は、この形で公開しています。
- **取得と設定のメソッド**: 値を読むだけのメソッドは `getPosition` のように `get` で始める名前にするのが Java の慣習です。確かめない設定のメソッド（`setPosition`）を機械的に付けないようにし、付けるなら、その中で規則を確かめます。
- **結果の返し方**: 拒否を例外（`IllegalStateException` など）で知らせる書き方もあります。この教材では、拒否は「よくあること」なので、戻り値で返しています。

:::
